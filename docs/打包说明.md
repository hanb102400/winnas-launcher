# 打包与分发说明

> WinNas Launcher 双形态分发：**常规安装版（NSIS）** + **绿色便携版（zip）**。

## 构建命令

```bash
npm run tauri build
```

产物输出到 `src-tauri/target/release/`：
- `bundle/nsis/` → `WinNas Launcher_0.1.0_x64-setup.exe`（安装版）
- `winnas-launcher.exe` → release 主程序（便携版基础）

> 注意：Tauri v2 的 `bundle.targets` 不支持 `zip`。**便携版需手动打包**：
> 把 `winnas-launcher.exe` + 一个名为 `portable.flag` 的空文件放入同名目录，zip 打包即可。

## 两种形态

### 1. 常规安装版（NSIS）

- 双击安装，写入开始菜单/卸载项；
- WebView2 Runtime 采用 `downloadBootstrapper`：安装时**联网引导**下载（Win10/11 通常已内置，跳过）；
- 配置/日志目录：`%APPDATA%\WinNasLauncher\conf\`。

### 2. 绿色便携版（zip）

- 解压即用，**不写注册表、不写 `%APPDATA%`**；
- WebView2：依赖系统内置 Runtime（Win10/11 标配，不内置固定版本）；
- 配置/日志目录：**exe 同目录** `conf\`。

**启用便携模式的开关**：在 exe 同目录创建一个名为 `portable.flag` 的空文件（程序检测到该文件后，配置读写切换到本地 `conf\`）。未创建时默认走 `%APPDATA%`。

```bash
# 便携版解压后，在 exe 同目录执行：
touch portable.flag   # Windows: type nul > portable.flag
```

## 配置文件清单（exe 同目录 / conf 目录）

| 文件 | 用途 |
|------|------|
| `setting.conf` | 轻量配置（autostart、exit_confirm、scale、initialized、menu_mode） |
| `apps.json` | 网格菜单列表（含图标 data URL、打开次数） |
| `logs/YYYY-MM-DD.log` | 运行日志（按日期命名） |
| `state_snapshot.json` | 系统状态快照（异常退出自愈用，4.13） |

## 崩溃恢复

- 启动时调用 `RegisterApplicationRestart`（WER），**崩溃时自动重启**（正常退出不重启）；
- 配合 4.13 系统状态快照：即使 WER 不可用，下次启动也会检测残留 running 标记自动恢复任务栏/桌面。

## 构建前提

- Node ≥ 20、Rust stable、Tauri v2 CLI；
- Windows SDK + VS Build Tools（C++，MSVC 工具链）；
- NSIS 打包需网络（下载 NSIS 工具链，首次构建自动拉取）。
